# AnchorVoyage

Complete static website for AnchorVoyage Shipping & Maritime Services.

Live website: https://anchorvoyage.com/
Enquiries: poxer7128@gmail.com

## Contents

45 main pages, seven Nigerian port guides, 15 specialist service pages, the nine-stage port journey, maritime articles, satellite maps, stock photography and a port film. HTML, CSS and JavaScript are the editable source; no build step or dependencies are required.

## Preview

With Node.js installed, run `node preview.cjs` and open http://127.0.0.1:4173/.

## Deploy

Netlify: use this repository with no build command and publish directory `.` or manually upload the website folder.
Cloudflare Pages: upload the website folder. The primary custom domain is anchorvoyage.com.

The contact form prepares an email in the visitor's email app. It does not send or store submissions on a server. No phone number is displayed.

## Media

Stock images illustrate the maritime industry and do not represent company personnel or owned assets. Attribution/source details are in assets-manifest.json, page-photography.json and individual page credits. Satellite imagery is for orientation, not navigation. Media remain subject to their respective providers' terms; this repository does not grant a separate license to third-party media.
